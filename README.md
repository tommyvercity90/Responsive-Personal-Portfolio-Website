# 🌐 Responsive Personal Portfolio Website











A modern, professional, and fully responsive personal portfolio website built using **HTML5, CSS3, and JavaScript**. It showcases a developer's profile, skills, projects, education, experience, and contact information through a clean and interactive interface.

## 📖 Overview

This project is designed to help developers create an online presence and present their work professionally.

The website features a dark-themed interface, smooth scrolling, interactive navigation, project cards, responsive layouts, and client-side contact form validation.

It is suitable for beginners learning front-end web development and can be customized for personal use.

## ✨ Features

- **Home Section:** Introduction, developer title, and call-to-action buttons.
- **About Section:** Personal introduction and professional interests.
- **Skills Section:** Displays technical skills in organized cards.
- **Projects Section:** Showcases projects with descriptions and technology tags.
- **Education & Experience:** Timeline-style presentation of academic and development experience.
- **Contact Form:** Validates name, email address, and message.
- **Responsive Navigation:** Mobile-friendly menu with a toggle button.
- **Active Navigation Highlight:** Highlights the section currently being viewed.
- **Responsive Design:** Layouts adapt to desktop, tablet, and mobile screens.
- **Modern Dark Theme:** Clean styling with accent colors and hover effects.
- **CSS Animation:** Floating hero element and interactive transitions.
- **Automatic Copyright Year:** Updates the year using JavaScript.
- **Accessible Design:** Semantic elements, form labels, and navigation accessibility attributes.
- **Reduced Motion Support:** Respects users' reduced-motion preferences.

> **Note:** The contact form currently performs front-end validation only. It does not send messages to an email address or server.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A modern web browser.
- [Visual Studio Code](https://code.visualstudio.com/) or another code editor.
- Optional: VS Code Live Server extension.
- Optional: Git for version control.

### Installation

**1. Clone the repository**

Replace `YOUR_USERNAME` with your GitHub username.

```
git clone https://github.com/YOUR_USERNAME/personal-portfolio.git
```

**2. Navigate to the project directory**

```
cd personal-portfolio
```

**3. Open the project in VS Code**

```
code .
```

**4. Run the website**

Open `index.html` in your browser, or right-click it in VS Code and select **Open with Live Server** if the extension is installed.

No package installation or build process is required.

## 🎨 Customization

Make the portfolio your own by updating the following elements.

### 1. Personal Information

Open `index.html` and replace the placeholder name, introduction, and developer title with your own details.

### 2. Skills

Edit the skills cards to reflect the technologies and tools you actually know.

### 3. Projects

Replace the sample projects with your own work. Update each project's title, description, technology tags, and GitHub repository URL.

### 4. Education and Experience

Update the timeline with your actual academic qualifications, courses, internships, or development experience.

### 5. Profile Image

Replace the emoji inside the `.profile-circle` element with an image of yourself if desired. Update `style.css` to size and crop the image appropriately.

### 6. Colors and Theme

Modify the CSS variables inside `:root` in `style.css`.

```
:root {
    --bg: #0b1120;
    --surface: #111b2e;
    --surface-light: #18243a;
    --text: #f1f5f9;
    --muted: #a3afc2;
    --accent: #38bdf8;
    --border: #26354d;
}
```

Changing these variables allows you to customize the website's background, text, accent, and border colors.
